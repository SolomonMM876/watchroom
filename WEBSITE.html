Watchroom website

Open the same website in desktop Brave or Chrome.

  1. Publish with GitHub Pages

    In your GitHub repository, open Settings → Pages. Under Build and deployment, choose GitHub Actions as the source. The Pages workflow builds and publishes the complete website folder.

  2. Open the website link

    After the deployment succeeds, find the HTTPS website address in Settings → Pages. Open that address and send it to your partner.

  3. Make a room

    Enter your name and click Make room. Use Invite partner to copy the private invitation and send it to your partner. They can open the invitation or choose Join room and paste its room code.

  4. Share the show

    Open the show in another browser tab. In Watchroom, click Share a tab, choose the show’s tab, and enable Share tab audio. Keep Watchroom open and use headphones.

Updates

Push your changes to GitHub. After the Pages workflow finishes deploying, refresh the website to load the update. If an old version remains, use a hard reload: ⌘ShiftR on Mac or CtrlShiftR on Windows.

Refresh after leaving your room. Closing or refreshing the host’s tab ends that room; make a new room afterward.

Run the app from HTTPS, or localhost for local testing. Camera, microphone, and screen sharing require a secure context and your browser’s permission. Opening website/index.html directly as a local file is unsupported.

GitHub Pages serves the website files. The public PeerJS Cloud service helps the two browsers connect, so both people need internet access. Some networks require TURN relay details in Settings. Protected streaming video may appear black.

Build and preview locally

From the project folder, build with Node.js. This script uses Node’s built-in tools and needs no npm packages.

node scripts/build-website.mjs

If Python 3 is installed, start a local preview and open http://localhost:8080. This local address is for testing on your computer.

python3 -m http.server 8080 --directory website
